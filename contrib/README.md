# contrib/

Tooling that is useful around the framework but is not the framework.
Nothing here is imported by `framework/` or needed to run a scenario.

- `recording/` — the aids used to record the 2026-09 presentation: a console
  that renders finalised log streams, a driver that runs real steps and
  narrates them, and a replayer for captured runs. See `recording/RUNBOOK.md`.
